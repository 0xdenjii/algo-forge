# Backtracking (Python)

Each file solves one problem and checks itself with asserts. Run any file with `python <file>`.

| File | Description |
|------|-------------|
| `0017_letter_combinations_of_a_phone_number.py` | All letter strings a phone digit string can spell. |
| `0022_generate_parentheses.py` | All well-formed strings of n parenthesis pairs. |
| `0037_sudoku_solver.py` | Sudoku solver using bitmasks and the fewest-candidates-first rule. |
| `0039_combination_sum.py` | Combinations that reach a target when numbers can be reused. |
| `0040_combination_sum_ii.py` | Combinations that reach a target, each number used once, with duplicates skipped. |
| `0046_permutations.py` | All permutations of distinct numbers, built by in-place swaps. |
| `0047_permutations_ii.py` | Unique permutations of input that has duplicates. |
| `0051_n_queens.py` | Every N-Queens board, tracking columns and diagonals in sets. |
| `0052_n_queens_ii.py` | Counts N-Queens solutions with bitmasks. |
| `0077_combinations.py` | All k-subsets of 1..n, stopping early when too few numbers remain. |
| `0078_subsets.py` | Power set of distinct numbers. |
| `0079_word_search.py` | Finds one word in a grid by DFS, with letter-count pruning. |
| `0089_gray_code.py` | Gray code sequence built by flipping one bit at a time. |
| `0090_subsets_ii.py` | Power set of input that has duplicates. |
| `0093_restore_ip_addresses.py` | All valid IPv4 addresses that fit a digit string. |
| `0126_word_ladder_ii.py` | All shortest word ladders: BFS builds a parent map, then backtracking lists the paths. |
| `0131_palindrome_partitioning.py` | Every split of a string into palindromes, with a DP palindrome table. |
| `0140_word_break_ii.py` | All sentences made from dictionary words, memoized by start index. |
| `0212_word_search_ii.py` | Finds many words in a grid with a trie that is pruned as words are found. |
| `0216_combination_sum_iii.py` | k distinct digits from 1-9 that sum to n. |
| `0254_factor_combinations.py` | Every way to write n as a product of factors. |
| `0282_expression_add_operators.py` | Places + - * between digits to hit a target; multiplication undoes the last term. |
| `0301_remove_invalid_parentheses.py` | Removes the fewest parentheses needed to make a string valid. |
| `0306_additive_number.py` | Checks whether a digit string forms an additive sequence. |
| `0351_android_unlock_patterns.py` | Counts Android unlock patterns using a jump table and board symmetry. |
| `0473_matchsticks_to_square.py` | Checks whether matchsticks can form a square, skipping symmetric choices. |
| `0491_non_decreasing_subsequences.py` | Distinct non-decreasing subsequences, deduplicated per recursion level. |
| `0526_beautiful_arrangement.py` | Counts divisibility-constrained permutations, memoized on a bitmask. |
| `0698_partition_to_k_equal_sum_subsets.py` | Checks whether an array splits into k subsets with equal sums (bitmask with memo). |
| `0797_all_paths_from_source_to_target.py` | All paths from source to target in a DAG. |
| `0980_unique_paths_iii.py` | Counts grid walks that visit every open cell exactly once. |
| `1219_path_with_maximum_gold.py` | Most gold collectable on a grid path with no revisits. |
| `1239_max_length_concatenated_unique_chars.py` | Longest concatenation with all-unique characters, using bitmasks. |
| `2397_maximum_rows_covered_by_columns.py` | Picks k columns to cover the most rows, using bitmasks. |
| `knights_tour_warnsdorff.py` | Knight's tour, trying the move with the fewest onward moves first (Warnsdorff). |
| `graph_m_coloring.py` | Graph m-coloring and chromatic number. |
| `hamiltonian_cycle.py` | Finds a Hamiltonian cycle or reports that none exists. |
| `subset_sum_bounded.py` | Subset sum with sum bounds that cut off hopeless branches. |
| `rat_in_a_maze.py` | All maze paths in D/L/R/U, in lexicographic order. |
| `cryptarithmetic_solver.py` | Solves SEND+MORE=MONEY-style puzzles by turning them into a weighted equation. |
